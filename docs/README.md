# EMM Live

A live map of `gm_bigcity`.

Connected players traverse the city in real time. Tracked position, role, and state,
streamed from the server straight into a browser window you can explore
on desktop or in VR.

No one online? It falls back to a replay of a past session,
so the city is never quite empty.

**Features**
- Live player tracking via WebSocket
- Automatic replay fallback when the server is empty
- Follow-cam with mouse orbit + scroll-to-adjust height
- Role-based puppet coloring.
- Desktop and VR support from a single build
